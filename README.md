# 海盗船 · 冒险湾

一款在浏览器中运行的 3D 海盗船游玩模拟器，支持电脑和手机。

**[进入游戏](https://jemiscxy.github.io/pirate-ship-simulator/)**

![海盗船封面](public/assets/pirate-cover-v1.png)

## 体验

- 在园区漫步，登船选择 40 个座位之一。
- 黑煤球主角，支持第一人称与第三人称。
- 压杆检查 4 秒，单轮运行 3 分 30 秒，包含起摆、高空摆动和减速回港。
- 正式运行时可以扩大视野，最多到 110°；只能恢复默认，不能继续望远放大。
- 随时打开暂停菜单下船，结束当前轮并回到本次登船前的位置，可以重新登船。
- 支持画质设置、声音开关和舒适视角。

## 电脑操作

| 操作 | 按键 |
| --- | --- |
| 移动 | W、A、S、D 或方向键 |
| 环顾 | 直接移动鼠标 |
| 自由观察，身体保持原方向 | 按住左 Alt；松开镜头回正 |
| 切换第一／第三人称 | V |
| 恢复初始朝向、俯仰和默认视野 | R |
| 入口附近选择座位 | E |
| 开始乘坐／暂停 | 空格 |
| 暂停、释放鼠标并打开菜单 | Esc |
| 运行时扩大视野／恢复默认 | 向下／向上滚轮 |

关闭菜单后会尝试重新锁定鼠标；若浏览器拒绝，请点击画面重试。设置、选座、切到后台或失去焦点时暂停计时。按 R 保留人物位置、人称和乘坐进度。第一人称默认视野 76°，第三人称默认 58°。

## 手机操作

建议横屏游玩。左侧摇杆移动，右侧拖动画面环顾；按住“自由观察”并用另一根手指拖动画面，松手镜头回正。右下按钮用于选座、开始、切换和归位；正式运行后可用左侧滑杆扩大视野。右上菜单用于暂停、设置及下船。

首次使用默认均衡画质。推荐使用新版 Chrome、Edge 或 Safari，并启用浏览器图形加速。

## 本地开发

使用 Node.js 24：

```sh
npm ci
npm run dev
```

打开终端提示的地址，路径为 `/pirate-ship-simulator/`。

```sh
npm test
npm run build
npm run preview
```

`src/` 为游戏源码，`public/assets/` 为本地资源，`tests/` 为游戏逻辑测试。Vite 将网站构建到 `dist/`；推送到 `main` 后由 GitHub Actions 自动构建并发布到 GitHub Pages，无需玩家电脑安装 Node.js，也不依赖开发者电脑持续开机。

## 建议验收

1. 电脑两种人称分别登船，运行中按 Esc 下船，检查返回位置；重新登船应开始完整新一轮。
2. 广角调到最大后按 R，并在暂停、压杆检查、停稳阶段尝试滚轮，确认视野限制。
3. 手机横竖屏同时移动和环顾，测试自由观察、广角及运行中从菜单下船。
4. 首次载入和刷新页面，确认封面、天空和纹理完整，手机没有横向溢出。

## 资源与许可

第三方代码许可见 [第三方许可.txt](第三方许可.txt)，纹理与天空来源见 [资源说明](public/assets/资源说明.txt)。海盗船、人物和园区几何由项目内代码构建。

当前建模参考游乐园海盗船的结构与观感，并非南宁方特设施的测绘复刻；3 分 30 秒与 70° 为本模拟器的体验参数。
